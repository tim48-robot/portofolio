# SFX candidates: sources & licenses

Collected 2026-11-08. All 18 files come from libraries that allow free commercial use, so no licensing contact is needed for anything in this folder. Third-party leads (paid or not downloadable from here) are listed at the bottom for your legal team.

**Edits applied to every file:** leading silence trimmed, a short fade-out where the original ran past the target length, peak-normalised to −1 dBFS, and exported as 16-bit / 44.1 kHz stereo WAV. Because every file peaks at the same level, set the actual playback volumes in code (clicks should play much quieter than impacts). Files marked *loop* were cut from the sustained part of the original and crossfaded so they repeat with no click.

## Leads not downloaded (for the legal team)

- **The actual Solo Leveling "system" sound** is copyrighted sound design owned by the studio/publisher (the anime is A-1 Pictures / Aniplex; the webtoon is D&C Webtoon / Kakao). Clips on YouTube and fan uploads to ringtone sites (e.g. zedge.net "Solo Leveling System", 1 s) are not licensed for reuse. Licensing would have to go through the rights holders. I did not rip these.
- **Sonniss #GameAudioGDC bundles** (sonniss.com/gameaudiogdc): royalty-free, commercial use, no attribution, studio-grade WAVs, with a multi-year archive. Strong source for charge, release and shatter. The site blocked automated download from here.
- **Freesound.org** (tag "powerup", e.g. user clif_creates' futuristic rising sounds): the license varies per file (CC0 / CC-BY / CC-BY-NC), so check each one. Downloading needs a login.
- **Pixabay sound effects**: Pixabay Content License (free commercial use, no attribution). Blocked from here.
- **Paid anime packs** worth auditioning: "Anime Game" by Epic Stock Media (gamedevmarket.net/asset/anime-game, includes 182 power-ups and 20 power auras) and "This Is Anime" (gamedevmarket.net/asset/this-is-anime-sound-effects-pack, includes charges, discharges and risers). Uppbeat's "Notification alert – glass ding / glass shimmer" (Soundroll) is a very close match for the ding, but its free tier requires attribution.
